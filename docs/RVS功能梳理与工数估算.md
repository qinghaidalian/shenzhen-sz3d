## 一、RVS 是什么

RVS（RobotVisionSuite）是图漾科技自研的 **3D 机器视觉开发平台**。核心范式是把各类 3D 视觉算子封装成**节点（Node）**，用户在画布上把节点互相连接、嵌套成组（Group），拼出完整的项目流程。目标是不写代码就能快速搭建、验证视觉方案并产出原型。

两个关键定位：

- **节点化可视化编程** + **结果可视化**（字符串、图像、点云、位姿都能在平台里直接看）。
- **CPU 版 / GPU 版**：二者仅在 AI 推理训练模块有差异，GPU 版推理训练更强但占用更大；另支持 **Docker 镜像**部署，便于用户自行编译插件算子（PluginNode）导入算子库。

## 二、功能一览

### A. 平台框架功能

| 模块 | 功能点 |
|---|---|
| 用户界面 | 节点画布、算子库面板、属性配置、结果可视化窗口、日志、布局管理 |
| 算子（Node） | 拖拽实例化、端口连接、类型校验、Group 嵌套成组 |
| 工程项目 | 项目保存/加载、流程组织 |
| 可视化 | 字符串/数值/图像/点云/位姿多类型结果展示，大规模点云 3D 渲染 |
| 二次开发 | 插件算子（PluginNode）编写与导入；Linux-C++ / Windows-C++ / Python 三种二开路径 |

### B. 算子库（RVS 的核心资产，共 14 大类）

| 分类 | 对应中文 | 典型能力 |
|---|---|---|
| **2D** | 2D 算子 | 2D 图像处理：滤波、边缘、形态学、二值化、ROI、特征等 |
| **3D** | 3D 算子 | 点云处理：滤波、降采样、分割、法向量、配准等 |
| **Basic** | 基础算子 | 触发、数据类型转换、逻辑/数学运算、流程控制 |
| **Box Unstack** | 拆垛算子 | 箱体检测、垛型分析、拆垛位姿输出（工业拆垛场景） |
| **Calibration** | 标定算子 | 相机内参标定、手眼标定（Eye-in-Hand / Eye-to-Hand） |
| **Communication** | 通讯算子 | TCP/IP、Modbus 等工业通讯收发 |
| **File** | 文件操作算子 | 图像/点云/文本等文件读写 |
| **ICP** | 点云模板匹配算子 | 基于 ICP 的点云配准/模板匹配定位 |
| **Motion Planning** | 机器人运动规划算子 | 轨迹/关节规划 |
| **Python** | Python 算子 | 用户用 Python 自定义算子逻辑 |
| **Robot** | 机器人算子 | 工业机器人接口、运动指令、状态读取 |
| **Surface** | 多边形表面算子 | 表面拟合、表面分析/缺陷 |
| **TyCamera** | 图漾相机算子 | 图漾 3D 相机 SDK 调用：枚举、连接、取流（彩色/深度/点云） |
| **Resource** | 资源类算子 | 机器人模型、工具模型等资源加载管理 |

### C. AI 模块（RVSAI）

- **推理服务**：模型加载与推理（GPU 版支持训练+推理，CPU 版侧重推理）。
- **图像标注**：训练前的数据标注工具。
- 深度学习训练与推理算子（图像检测/分割类）。

### D. 标定专项（手眼标定工具链）

- 手眼标定工具（独立工具）。
- 六轴机器人手眼标定流程。
- 四轴机器人手眼标定流程。

### E. 模型制作

- 机器人模型库 / 机器人模型制作 / 工具（夹具）模型制作，用于 3D 场景中的碰撞与可视化。

### F. 典型案例（即开箱方案模板）

- 自动拆垛、模板匹配、深框抓取。

## 四、工数风险提示（真正吃时间的地方）

1. **3D 点云渲染与大数据 LOD**：500 万点 ≥ 30 FPS 是硬指标，HelixToolkit.SharpDX 调优风险最高。
2. **点云算法生态**：.NET 没有 PCL/Open3D 的原生等价物，需 C++ 互操作或自研，拆垛/配准/表面处理工数极易翻倍。
3. **标定精度**：手眼标定不是写完就行，精度验证和真机标定迭代很耗时。
4. **相机 SDK 与真机联调**：camport3 P/Invoke 封装 + 真实硬件调试需额外预留时间。
5. **插件热重载**：AssemblyLoadContext 卸载依赖 GC，容易出现静默卸载失败，需要专门排查。
